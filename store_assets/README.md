# Play Store Assets Checklist

## Required Files for Play Store

### 1. App Bundle (AAB)
- File: `bizinote.aab`
- Created with: `npx expo build:android --type app-bundle`
- Upload to Play Store Console

### 2. Store Listing Assets

#### App Icon
- ✅ Already have: `assets/icon.png` (1024x1024)
- ✅ Already have: `assets/adaptive-icon.png` (1024x1024)

#### Feature Graphic (1024x500 pixels)
- Create: `store_assets/feature_graphic.png`
- Shows app logo with "Bizinote - Business Management"

#### Screenshots (Required: 5-8 images)
- Phone screenshots (320x384 to 3840x4608)
- Required screens:
  1. Dashboard with stats
  2. Product management
  3. Customer list
  4. Bill creation
  5. Reports chart
  6. Settings/profile
  7. Invoice PDF preview
  8. Low stock alerts

#### Promotional Video (Optional)
- 30-60 seconds
- Shows app features
- Upload to YouTube, link in Play Store

- ✅ Created: `privacy_policy.html`

- No restricted content

### 6. Technical Requirements
- Target API Level: 34 (Android 14)
- 64-bit architecture support
- App signing key
- Content rating questionnaire completed

## Upload Process

1. **Google Play Developer Account**
   - Pay $25 fee
   - Complete developer profile

2. **Create New App**
   - Select "Business" category
   - Fill in app details

3. **Upload App Bundle**
   - Upload `bizinote.aab`
   - Wait for processing

4. **Store Listing**
   - Add app name and description
   - Upload screenshots
   - Add feature graphic
   - Add privacy policy URL

5. **Content Rating**
   - Complete questionnaire
   - Get rating: "Everyone"

6. **Pricing & Distribution**
   - Set price: Free
   - Select countries for distribution

7. **Release**
   - Submit for review
   - Wait for approval (2-7 days)
   - Publish to Play Store

## Timeline
- **Setup:** 1-2 days
- **Review:** 2-7 days
- **Publish:** After approval

## Cost
- **Developer Account:** $25 (one-time)
- **Hosting:** $5-10/month (Hostinger)
- **Total Launch Cost:** ~$35
